How to play

zainVPN makes your friends look like they're on your home network.
  1. Choose LAN or System LinkIn the game's multiplayer menu, pick LAN (sometimes called System Link) instead of Online.
  2. Join your friendsGames hosted by friends appear in the game's list automatically.
  3. Asked for an IP address?Use the host's Virtual IP from the Players list. If you're hosting, share yours from This PC.
  4. Friends can't see your game?Allow the game through Windows Firewall when Windows asks, then restart the game.
